Built for local Markdown work

Open one file, browse a folder, edit with the toolbar, preview rendered output, and export a standalone HTML copy.

Split reading and editing

Switch between preview, raw Markdown, and split mode without leaving the desktop app.

Offline Mermaid support

Mermaid is bundled with the app, so diagrams render without depending on a CDN.

Windows file workflow

Open folders, remember recent files, install per-user file integration, and uninstall cleanly.

Download, verify, install

Use the installer for normal desktop use. Use the portable ZIP when you want to extract and run without installing.

  1. Download the latest Windows installer from the release page.
  2. Compare the file hash against SHA256SUMS.txt.
  3. Run the installer and launch MD Reader from the Start menu.
