# MD Reader {version}

## Download

- Installer: `MDReader-v{version}-windows-x64-setup-unsigned.exe`
- Portable ZIP: `MDReader-v{version}-windows-x64-unsigned.zip`
- Checksums: `SHA256SUMS.txt`

## Install

Run the installer for normal use. Use the portable ZIP only when you want to extract and run MD Reader without installing.

## Windows trust note

If the installer filename includes `unsigned`, it has not been Authenticode-signed. Windows SmartScreen may show a warning until the project publishes signed builds and develops reputation.

Verify downloads with `SHA256SUMS.txt` before installing.

## Notes

- The installer registers MD Reader as an available Markdown opener for the current Windows user.
- If Windows keeps another default app for `.md` files, choose MD Reader from **Settings > Apps > Default apps**.
