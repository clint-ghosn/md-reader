# MD Reader Innovation Ideas

## Beginner First Editing

- Guided Markdown Mode: toolbar actions insert editable placeholders and briefly explain the result.
- Block Inserter: a plus button for meeting notes, README sections, changelog entries, decision logs, tables, checklists, callouts, and code blocks.
- Markdown Coach: subtle hints when users type patterns like `#`, `- [ ]`, or fenced code blocks.
- Starter Templates: New README, Meeting Notes, Project Plan, Troubleshooting Guide, Daily Notes, and Release Notes.
- Form Assisted Blocks: optional simple forms for links, images, tables, and front matter that still save plain Markdown.

## Navigation And Understanding

- Preview Click To Source: click rendered preview content and jump to the matching source line.
- Document Outline: show headings as a navigable table of contents.
- Workspace Map: when a folder is open, show links between Markdown files and unresolved references.
- Backlinks: show which files link to the current note.
- Command Palette: quick access to open files, insert blocks, export, toggle preview, and jump to headings.

## Quality Tools

- Document Health Check: find broken image links, broken relative links, duplicate headings, missing title, malformed tables, and very long lines.
- Diff Before Save: show changes since the file was opened.
- Autosave Recovery: keep recovery drafts without silently overwriting the original file.
- Readability Metrics: approximate reading time, word count, heading depth, and checklist completion.
- Markdown Lint Suggestions: beginner-friendly guidance for common structural issues.

## Publishing And Export

- Export Pack: export HTML, PDF, and a single-folder web page with local images copied beside it.
- Share Preview: generate a temporary read-only HTML preview for review.
- Print Friendly Mode: a clean print stylesheet for docs and notes.
- Theme Packs: GitHub, documentation, academic, and distraction-free reading styles.
- Static Site Folder: export a folder of Markdown files as a small linked website.

## Smart Input

- Smart Paste: paste URLs as links, image paths as images, CSV as Markdown tables, and copied code as fenced blocks.
- Image Helper: copy images into an `assets` folder and insert a relative Markdown image path.
- Table Editor: edit Markdown tables in a small grid UI.
- Checklist Mode: quickly add, complete, reorder, and filter tasks.
- Link Picker: choose another Markdown file from the open folder when creating a link.

## Reader And Focus Modes

- Reader Mode: hide editor controls and show a polished reading view.
- Focus Writing Mode: hide drawer and preview, increase editor width, and reduce chrome.
- Split Presets: editor only, preview only, side by side, stacked.
- Typewriter Scroll: keep the active line centered while writing.
- Session Restore: reopen the last workspace and files exactly as they were.
